I am **Dheeraj Mishra**, a B.Tech Computer Science Engineering student primarily focused on building my career as a **Data Analyst**.

My main professional focus is **Data Analytics** — working with data to clean, transform, analyze, visualize, identify patterns, answer business questions, and generate meaningful insights for decision-making.

I work primarily with **Python, SQL, Pandas, NumPy, Excel, Power BI, Matplotlib, and Seaborn** for analytical workflows.

<summary><strong>01 — Real Estate Data Analysis</strong></summary>

### Overview

A data analysis project focused on understanding property pricing patterns and relationships within a real estate dataset.

### Dataset

- **19,515 records**
- **12 original columns**
- **5,292 duplicate records removed**
- Property-level information covering area, price, property type, locality, BHK, RERA status, builder and listing source.

### Analysis Performed

- Data cleaning
- Duplicate removal
- Missing-value inspection
- Descriptive statistics
- Feature exploration
- Property-type analysis
- BHK analysis
- Locality analysis
- RERA analysis
- Builder and listing-source analysis
- Outlier analysis
- Area vs price relationship analysis
- Rate-per-square-foot analysis
- Data visualization

### Key Finding

The observed correlation between property area and price was approximately:

**0.1974**

This indicates a positive but relatively weak linear relationship within the analyzed dataset.

<summary><strong>03 — Fake News Detection</strong></summary>

### Overview

A Natural Language Processing and Machine Learning project designed to classify news articles as **Fake** or **True** using textual features and supervised classification algorithms.

### Workflow

```text
News Dataset
      ↓

      ↓

      ↓
```

- Random Forest
- Gradient Boosting
