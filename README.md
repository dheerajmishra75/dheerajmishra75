# Featured Projects

<details>
<summary><strong>01 — Real Estate Data Analysis</strong></summary>

### Overview

A data analysis project focused on understanding property pricing patterns and relationships within a real estate dataset.

### Dataset

- **19,515 records**
- **12 original columns**
- **5,292 duplicate records removed**
- Property-level information covering area, price, property type, locality, BHK, RERA status, builder and listing source.

### Analysis Performed

- Data cleaning
- Duplicate removal
- Missing-value inspection
- Descriptive statistics
- Feature exploration
- Property-type analysis
- BHK analysis
- Locality analysis
- RERA analysis
- Builder and listing-source analysis
- Outlier analysis
- Area vs price relationship analysis
- Rate-per-square-foot analysis
- Data visualization

### Key Finding

The observed correlation between property area and price was approximately:

**0.1974**

This indicates a positive but relatively weak linear relationship within the analyzed dataset.

### Stack

| Category | Technologies |
|---|---|
| Language | Python |
| Data Processing | Pandas, NumPy |
| Visualization | Matplotlib, Seaborn |
| Environment | Jupyter Notebook |

### Workflow

